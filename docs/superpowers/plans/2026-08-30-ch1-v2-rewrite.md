> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce `v2/ch01.md` — the second-edition chapter 1 (~13–15k words, nine sections per the spec outline) — through a five-stage inkwell pipeline with the Hemingway voiceprint active, panel-scored ≥8.5 from 6.8.

## Global Constraints

- **Voice:** the Hemingway voiceprint profile is ACTIVE in every drafting/revision dispatch — the prompt names it ("the hemingway voiceprint profile is active for this piece"). Conformance measured with `python3 /home/charl/inkwell/skills/voiceprint/scripts/conformance.py /home/charl/inkwell/skills/voiceprint/profiles/hemingway.metrics.json <draft>` after stages A, C, D; final target verdict `close`, number reported regardless.
- **Anti-slop:** tell-audit findings resolved every Gottlieb round; humanizer as final surface pass; `python3 .claude/skills/math-explainer/scripts/draft_lint.py <file>` must exit clean at stage D.
- **Length:** final 13,000–15,000 words. Section budgets per spec §4 (±20% per section).

- **`proving-nothing.md` is never modified.** Deliverables: `v2/README.md`, `v2/ch01.md`. Stage files in `v2/.work/ch01/` (gitignored).
- Work on branch `v2/ch01`; commit after every task; PR to main at the end.
